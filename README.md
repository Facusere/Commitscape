# Commitscape (Repoescena) · Paisaje y Escenario 3D de Perfiles de GitHub

## Descripción

**Commitscape** (evolución conceptual de **Repoescena**) es una aplicación web interactiva que transforma cualquier perfil y portafolio de código de GitHub en un escenario espacial tridimensional vivo. Diseñado bajo una filosofía ligera, directa y sin compilaciones ni dependencias pesadas, convierte métricas técnicas —repositorios, lenguajes, estrellas y actividad de commits— en una galería visual inmersiva, tangible y fácil de explorar desde el navegador.

Su identidad estética se apoya en **diseños en 3D de los objetos**: cada componente del perfil adquiere volumen físico, caras iluminadas, biseles especulares, profundidad en el eje `Z` y movimiento reactivo al puntero, reemplazando los tableros planos tradicionales por una experiencia visual llamativa y memorable.

## ¿De qué se trata?

Commitscape convierte la consulta de perfiles de GitHub en un recorrido espacial por piezas tridimensionales interactivas:

- **Portada de tendencias y Red Neuronal de Tecnologías**: Inicio en vivo con una red neuronal estructurada en 3 capas (**Grandes Categorías → Lenguajes Asociados → Stacks**) alimentada con publicaciones recientes de toda la comunidad en los últimos 7 días (sin sesgo de estrellas), panel de contexto interactivo y barra de búsqueda de usuarios en el encabezado minimalista.
- **Skyline prismático y sistema orbital de lenguajes**: Torres volumétricas extruidas y esferas orbitales espaciales que representan tanto el lenguaje predominante por repositorio como el desglose real en bytes de código.
- **Paisaje topográfico de actividad 3D (*Commitscape Terrain*)**: Matriz arquitectónica de columnas y vóxeles luminosos que elevan la cadencia de commits y eventos públicos recientes como un relieve urbano de código.
- **Holocarta de identidad y cápsula orbital del avatar**: Emblema multicapa en profundidad donde la foto del desarrollador levita entre anillos orbitales y medallones 3D que exhiben repositorios, seguidores, estrellas acumuladas, forks y antigüedad en la plataforma.
- **Cartuchos 3D de repositorios e inspector de doble cara**: Tarjetas estratificadas en varias cotas del eje `Z` con física de inclinación, brillo especular dinámico, gemas 3D por lenguaje y giro completo de `180°` para inspeccionar composición, pulso de actividad y enlaces de cada proyecto.
- **Arena de duelo 3D entre desarrolladores**: Comparador espacial cara a cara para contrastar dos usuarios de GitHub mediante prismas enfrentados, balanza de impacto e intersección de tecnologías.
